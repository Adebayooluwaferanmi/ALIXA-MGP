## Suggested GitHub Project fields
Status: Backlog / Ready / In progress / In review / Blocked / Done.
Phase: 0, 1A, 1B, 2, 3, 4, 5.
Priority: P0 / P1 / P2.
Workstream: Product, Frontend, Platform, Media, Audio, Capture, Infra/Security, QA.
Target week, owner, dependencies, budget impact, sprint, acceptance demo.

**Project board status:** This repository contains issue tracking and a roadmap. A GitHub Projects board is not automatically created by ordinary repository issue creation; provision separately through an authorized Projects integration or GitHub UI if needed.

## First actions at kickoff
Review #2–#4, nominate issue owners, decide exact team capacity and budget, set kickoff date, approve architecture decisions, then move to implementation.
