## Day 1 architecture decision worksheet

| Decision | Preferred candidate (provisional) | Evaluate against |
|---|---|---|
| Web UI | React + Next.js + Monaco + Remotion Player | Editing responsiveness, bundle previews, accessibility |
| API/control plane | TypeScript/Node.js first for shared contracts; FastAPI is viable alternative | Type reuse, operational simplicity, developer fluency |
| System of record | PostgreSQL | Transactions, immutable versions, access |
| Queue | Redis-backed queue with durable PostgreSQL job state | Recovery, retries, budgets and correctness |
| Asset exchange | S3-compatible object store | Hashes, short-lived links, lifecycle rules, Linux portability |
| Creative engine | Remotion/React/TypeScript | Existing ecosystem, programmatic composition, cache |
| Capture | Local browser APIs first; Playwright isolated Chromium later | Cost, authorization, safety, browser support |
| Audio | Modular TTS provider, FFmpeg mastering, licensed music library | CPU-first use, license, voice quality |
| Execution isolation | Ephemeral non-root Linux sandbox, cgroups v2/seccomp + egress restrictions; stronger VM boundary if adversarial multi-tenant | Host safety, cost, kernel escape threat |

### Day 1 questions requiring a decision
1. Is initial deployment single trusted owner or multi-tenant users executing hostile source? This determines sandbox strength and release restrictions.
2. Must the local development stack function fully without external cloud services? **Default: yes**, except optional import connectors.
3. What is the maximum affordable monthly operating budget and acceptable render latency? If unknown, use **benchmark-first** policy rather than a fictional figure.
4. Is custom TSX editing a Week 1 development requirement? **No**: contract and isolation boundary now; implementation later.
5. Which functions require review before publication (external website captures, cloned voices, proprietary assets)? **Default: all external and synthetic assets carry rights/privacy metadata and publication approval**.
